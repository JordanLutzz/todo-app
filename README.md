# To-Do App

A simple web-based to-do list built with Python and Flask. Users can add, 
complete, and delete tasks, with data saved to a JSON file so tasks persist 
between sessions.

## Features
- Add new tasks
- Mark tasks as complete
- Delete tasks
- Data persists using JSON file storage

## Tech Stack
- Python
- Flask
- HTML/CSS
- JSON for data storage

## How to run
1. Clone this repo
2. Install Flask: `pip install flask`
3. Run: `python app.py`
4. Open `http://127.0.0.1:5000` in your browser

## What I learned
Building this project helped me understand how backend logic (Python/Flask) 
connects to a frontend (HTML templates), how to persist data between sessions 
using file storage, and how routes and forms work together in a web app.
